# Código de conducta de YouTube Music Sync · PreMiD

Estas pautas se aplican a las conversaciones, los reportes y las revisiones del proyecto. Tratá a quienes participan con respeto, explicá tus desacuerdos con ejemplos y pedí permiso antes de compartir material de otra persona.

Si necesitás mostrar un problema, describí la versión de PreMiD y la secuencia de cambios de pista. Revisá las capturas antes de publicarlas para proteger la privacidad de quienes aparecen.

Si recibís acoso, amenazas o ataques personales, podés usar las opciones de reporte de GitHub o pedir al mantenedor un canal privado. El mantenedor puede moderar comentarios y limitar la participación según la gravedad de la situación.
